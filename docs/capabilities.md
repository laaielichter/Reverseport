# What it does

### Understand and go deep

| Target                             | What you get                                                                                                                                                                                                                                                                                       | Needs                                                                                     |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Source projects and exported games | Engine + version (Godot, Unity, Unreal, GameMaker, RPG Maker, Ren'Py, LÖVE, Defold, Bevy, MonoGame, web, Electron, Flutter, .NET, Go, Rust…), dependencies, cycles, scenes, symbols                                                                                                                | Nothing                                                                                   |
| Packs and archives                 | Godot `.pck` (also embedded in the `.exe`), zip/apk/jar/ipa, `.unitypackage`, tar.gz, asar, Ren'Py `.rpa`, GameMaker `data.win`, Unreal `.pak`, FMOD and Wwise banks, Quake `.pak`, Doom `.wad`, Flash `.swf` — list and extract; XNB, VPK and more recognised                                     | Nothing                                                                                   |
| Godot exports                      | Compiled scripts, scenes and resources back to an editable project; imported textures, audio and translations back to PNG, WAV, OGG, MP3 and CSV ([how](godot-pck.md#back-to-an-editable-project))                                                                                                 | Nothing                                                                                   |
| Ren'Py and GameMaker               | Compiled `.rpyc` scripts back to `.rpy`; GML bytecode of a `data.win` back to `.gml` ([Ren'Py](renpy.md), [GameMaker](gamemaker.md))                                                                                                                                                               | Nothing                                                                                   |
| Unreal                             | `.uasset`/`.umap` names, imports and exports, IoStore `.utoc` file lists, `.locres` texts, GVAS saves ([how](unreal.md))                                                                                                                                                                           | Nothing                                                                                   |
| Unity IL2CPP                       | Classes, methods and literals from `global-metadata.dat`, plus a C# skeleton                                                                                                                                                                                                                       | Nothing                                                                                   |
| Unity builds and asset bundles     | Every object by class and name, scenes, C# scripts in use; textures → PNG, meshes → OBJ, audio, text, JSON (UnityFS LZ4/LZMA)                                                                                                                                                                      | Nothing                                                                                   |
| Executables at a glance            | PE, ELF, Mach-O, wasm: sections, imports, strings; detected packers, protectors, installers and compilers with the evidence; capabilities from imports; PE version info, manifest, icons and Rich header; ELF build-id and DWARF producers; Mach-O signature and entitlements; wasm function names | Nothing                                                                                   |
| Native binaries in depth           | Mach-O, ELF, PE, wasm: functions, pseudocode, strings, xrefs, call paths, layout                                                                                                                                                                                                                   | Ghidra, Hopper or IDA for decompilation ([setup](getting-started/installation.md#hopper)) |
| .NET assemblies                    | Metadata, CIL, native boundaries, type- and method-level build comparisons                                                                                                                                                                                                                         | Nothing                                                                                   |
| Android and iOS packages           | `.apk`: decoded manifest, labels from `resources.arsc`, native ABIs; `.ipa`: `Info.plist` summary ([how](android-ios.md))                                                                                                                                                                          | Nothing                                                                                   |
| Android in depth                   | Classes, decompiled methods, references, resources, devices                                                                                                                                                                                                                                        | JADX / Apktool / adb ([guide](guides/android/android-analysis.md))                        |
| Save files                         | Layers, fields with roles, verified checksums, a diff of two saves; also GVAS, Apple property lists and Steam VDF/ACF                                                                                                                                                                              | Nothing                                                                                   |
| Unknown binary formats             | The layout from 2 to 32 sample files: fields with evidence, record tables, checksums and a Kaitai `.ksy` draft ([how](re-struct.md))                                                                                                                                                               | Nothing                                                                                   |
| JavaScript and Electron            | Modules, imports, source maps, Electron boundaries, runtime observation                                                                                                                                                                                                                            | Nothing; a browser for runtime                                                            |
| Websites                           | Page, network and runtime evidence; one element by CSS selector (cropped image, HTML, computed CSS); stack fingerprint without files                                                                                                                                                               | A browser for runtime                                                                     |
| Firmware, EVM, crashes, captures   | Regions and extraction, selectors, recorded crashes, HAR/mitmproxy captures                                                                                                                                                                                                                        | See the [guides](index.md)                                                                |

Every tool result is checked for text that is written for the AI agent that reads it. A hit adds an `untrusted` note;
nothing is removed. It matches known English phrasings only. See the [injection shield](injection-shield.md).

### Formats: what is read and what is only reported

"Reported" means ReversePort names it and stops there. It is detection only: nothing is unpacked, decrypted or
patched.

| Format                                                                                                                           | Tool                      | Read                                                                                                                                    | Only reported                                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Godot `.pck`, also inside an `.exe`                                                                                              | `re_archive`              | Entries, sizes, Godot version, pack format 1–4; extract, MD5-checked                                                                    | Encrypted packs and entries                                                                                        |
| Godot `.gdc`, `.scn`, `.res`, `project.binary`                                                                                   | `re_decode`               | `.gd`, `.tscn`, `.tres` and `project.godot` (Godot 3 bytecode v10–13, Godot 4.3+ tokens); comments and formatting are not in the export | Encrypted scripts (`.gde`)                                                                                         |
| Godot `.ctex`, `.stex` textures                                                                                                  | `re_decode`               | PNG: stored PNG copied, lossless WebP decoded; raw 8-bit, DXT1/5, RGTC and ETC/ETC2 decoded                                             | Basis Universal, ASTC and BPTC                                                                                     |
| Godot `.sample`, `.oggvorbisstr`, `.oggstr`, `.mp3str`                                                                           | `re_decode`               | WAV (PCM, IMA ADPCM, QOA, loop points kept), OGG, MP3                                                                                   |                                                                                                                    |
| Godot `.translation`                                                                                                             | `re_decode`               | CSV for the keys that can be matched (keys are stored as hashes)                                                                        | Texts without a key are listed apart                                                                               |
| Unity asset bundles, `.assets`, `data.unity3d`                                                                                   | `re_archive`              | Objects, scenes, scripts in use; Texture2D as PNG, Mesh as OBJ, AudioClip as FSB5, TextAsset                                            | ASTC as `.astc`, BC6H/BC7 as `.dds`, other formats raw; encrypted bundles                                          |
| Unity IL2CPP `global-metadata.dat` (v24–31)                                                                                      | `re_il2cpp`               | Assemblies, types, method names, string literals, C# skeleton                                                                           | Encrypted or obfuscated metadata; method bodies are native code                                                    |
| Ren'Py `.rpa`                                                                                                                    | `re_archive`              | File list, extract                                                                                                                      |                                                                                                                    |
| Ren'Py `.rpyc`, `.rpymc` (6.99–8.x)                                                                                              | `re_decode`               | `.rpy` text: labels, dialogue, menus, screens, ATL, translations                                                                        | A node class the printer does not know becomes a counted comment line                                              |
| GameMaker `data.win`, `game.unx`, `game.ios`, `game.droid`                                                                       | `re_archive`, `re_decode` | Names, textures (PNG/QOI), audio (WAV/OGG); GML bytecode 14–17 as `.gml` per script, object event and room                              | Entries the decompiler is not sure about stay GML assembly with the reason; YYC builds                             |
| Unreal `.pak` v1–v11                                                                                                             | `re_archive`              | Entries, compression; stored and Zlib extract                                                                                           | Encrypted paks                                                                                                     |
| Unreal `.uasset`, `.umap` (UE4 214–522, UE5 1000–1018)                                                                           | `re_unreal`               | Package summary, names, imports, exports                                                                                                | Property bodies; other versions stop with `partial`                                                                |
| Unreal IoStore `.utoc`                                                                                                           | `re_unreal`               | Header, compression methods, file list with sizes                                                                                       | Encrypted index; Oodle-compressed data                                                                             |
| Unreal `.locres` (versions 0–3), GVAS `.sav` (UE 4.x to 5.3)                                                                     | `re_unreal`, `re_save`    | Namespaces, keys and texts; save header and tagged properties                                                                           |                                                                                                                    |
| Android `.apk`                                                                                                                   | `re_archive`              | Binary `AndroidManifest.xml` decoded, labels through `resources.arsc`, native ABIs                                                      | Encrypted entries                                                                                                  |
| iOS `.ipa`                                                                                                                       | `re_archive`              | `Info.plist`: bundle id, version, minimum OS, URL schemes, permission texts                                                             | Encrypted entries                                                                                                  |
| Apple property lists (`bplist00` and XML), Steam VDF/ACF                                                                         | `re_save`                 | Every field with type, sample and a guessed role                                                                                        |                                                                                                                    |
| PE, ELF, Mach-O, WebAssembly, Java `.class`, Android `.dex`, Lua, Python bytecode                                                | `re_binary`               | Sections with entropy, imports, exports, strings, version info, signing                                                                 | Packers and protectors (UPX, ASPack, MPRESS, Themida, VMProtect, Enigma) are named with the evidence, not unpacked |
| FMOD `.bank`/`.fsb`, Wwise `.bnk`, Flash `.swf`, Quake `.pak`, Doom `.wad`, Electron `.asar`, Unity WebGL and Emscripten `.data` | `re_archive`              | List and extract                                                                                                                        |                                                                                                                    |
| Save files: gzip/zlib, base64, LZ-String, JSON, XML, INI, Godot `store_var`                                                      | `re_save`                 | Fields, roles, verified checksums                                                                                                       | Encrypted, XOR-obfuscated, .NET BinaryFormatter and pickle content                                                 |
| Any binary format, from samples                                                                                                  | `re_struct`               | A hypothesis of the layout from the samples given                                                                                       |                                                                                                                    |

How far each reader was tested:

- Ren'Py: on the Ren'Py 8.2 test cases, 28 of 28 are byte-identical to unrpyc's output. The printer is a port
  of [unrpyc](https://github.com/CensoredUsername/unrpyc) (MIT, notice kept).
- GameMaker: on three real builds of an open game, 3,747 of 3,752 code entries were decompiled, with 0 unknown
  instructions.
- Unreal: 413 public packages were parsed. The IoStore `.utoc` reader is tested on self-built fixtures only.
- Godot imported resources: the readers are tested on self-built fixtures only.
