## Three bounded follow-up questions

1. **Rust dependency identity:** inspect a public cargo-auditable binary, find
   exact dependency/version edges and retain complete source Evidence. Compare
   existing delivery first; independently decode its auditable section. Include
   a small binary and account for all discovery, queries and serialization.
2. **Apple UI graph lookup:** on macOS, locate a specific control/outlet in a
   real Transmission/XLD NIB graph using existing summary/document pages.
   Compare equivalent complete questions and independently check archive
   records. Historical byte reductions alone are not the completion criterion.
3. **Reference/source comparison:** import a pinned public source tree and
   answer one source-to-bundle identity question through existing workflows.
   Independently check file manifests, symlink/unknown semantics and selected
   matches; measure repeated traversal and retained representation before
   proposing an index or cache.

Each lane stops with a measured benefit, an evidenced no-change decision, or an
explicit unavailable prerequisite. Rizin/Cutter and device/live workflows stay
visible as additional gaps; no new execution, injection or mutation authority is
implied by this review. No all-provider run or new API is justified by counts.
