Reverse engineer anything. Port it anywhere.

An MCP server and CLI that lets your coding agent take apart apps, games, binaries and websites, then rebuild them or port them to Godot, Unity, Unreal, three.js or another language. It runs on your machine and only reads the target.

npx reverseport setup

Needs Node.js 22.19 or newer. Setup connects Claude Code, Codex, Cursor, Gemini CLI, Copilot, OpenCode and more, and backs up your config first.

Source on GitHub npm package

Ask your agent. It picks the tools.

You keep talking in plain sentences. ReversePort gives the agent one consistent set of tools, and every answer comes with the evidence behind it.

  • What is this game made with, and how is it built?
    re_scan finds the engine and version, languages, entry points and how it starts, also for exported builds.
  • What changed between build 43 and 44?
    re_compare diffs folders, packs and binaries, biggest changes first.
  • Decompile the function that saves settings and explain it.
    Opens the binary through Ghidra, Hopper or IDA, finds the function and shows pseudocode with references.
  • What is this game made with? I don't have the files.
    re_lookup checks public sources: engine with a confidence level, stack, file layout and open-source remakes.
  • Rebuild the movement of this game in Godot.
    re_blueprint writes a clean-room spec: systems, values to measure on the original, a parity table and a project skeleton.
  • Port my Godot game to Unity.
    port_plan, then the agent ports unit by unit, and port_verify checks that nothing was left behind.

Findings come with their evidence

An agent that says "done" should be able to show why. A proof case ties every claim to saved evidence and keeps open questions open until they are answered.

  • Evidence is saved with its SHA-256, so a later check sees if a file or tool result changed.
  • Observed claims name a competing explanation and the check that would prove them wrong.
  • In Claude Code, hooks ask first before a tool runs or attaches to a program, refuse remote debugger endpoints, and stop a "done" while a proof case fails its check.
  • With Stashpad, findings become memories you approve, and the next session gets a handoff note that is read once.
reverseport case init --question "What changed between build 43 and 44?" --target ./builds
reverseport case evidence <caseId> --file build-44/Game.pck --locator "build-44" --note "pack"
reverseport case claim <caseId> --statement "Build 44 adds ui/minimap.gd" --evidence '["E001"]'
reverseport case check <caseId>

What it does and does not do

So you know what to expect before you install.

It does

  • Run locally. Nothing is uploaded to an analysis service and there is no extra API bill.
  • Only read the target. Output always goes to a new folder.
  • Work right after cloning for scanning, packs, lookup, blueprints and porting. No build step.
  • Drive Ghidra, Hopper, IDA and JADX when you have them installed, and show the evidence behind each conclusion.

It does not

  • Crack, decrypt or bypass DRM, anti-cheat or licensing. Use it on software you own or may analyse.
  • Port code by itself. Your agent writes the code; ReversePort plans, gives API maps and checks the result.
  • Decompile without a backend. Native decompiling needs Ghidra, Hopper or IDA.
  • Convert Unity scenes to Unreal yet. That route ports code and transforms only.

Get started

Three steps, about two minutes.

  1. Connect your agents. Pick them, review the changes and approve.

    npx reverseport setup

  2. Restart your agent so it loads the new MCP server and skill.

  3. Ask something real, for example:

    What is ./MyGame made with? Then plan a port to Unity.

Using Claude Code? You can install the plugin instead, which adds the porting skills and the port-architect agent:

/plugin marketplace add laaielichter/reverseport
/plugin install reverseport@reverseport

ReversePort is free and open source under the MIT license. The deep-analysis engine is based on REA: Reverse Engineer Anything. Proof cases come from Digfox, the hooks follow rea-jev and the challenge self-check uses rea-lab, all MIT.
